# GBA1 MAVE Analysis Pipeline

Analysis scripts for: **A harmonized functional reference framework for GBA1**

This repository contains the analysis scripts used to process, analyse and plot the data presented in the manuscript.

## Data and analysis pipeline

The analysis scripts are provided in this repository.

All datasets required to run the scripts, including the input files for each step, are hosted separately on Zenodo because of file size limits:

➡ [Download the dataset from Zenodo (DOI: 10.5281/zenodo.23169564)](https://doi.org/10.5281/zenodo.23169564)

## Step-by-step analysis

First, download the Zenodo dataset and place it in the working directory.

### 1. Design mutagenic oligos

* Run `MOLigos_Script_GBA1.ipynb` to generate the mutagenic oligos used to mutagenise GBA1 codons 2 to 536.
* The oligos are generated as 10 separate pools, matching the 10 pools in which mutagenesis was carried out before they were combined.
* The output is written in Excel format to:

```
  results/mutagenesis_primers/
```

* The oligo sequences are reported in Supplementary Table 6 (summary of primers). No figure is generated in this step.

### 2. Align PacBio HiFi reads to the GBA1 amplicon

* Run `process_PacBio_sequencing.py`. This processes the PacBio Revio sequencing output:

```
  m84140_250314_170434_s1.hifi_reads.bc1012.fastq.gz   (GEO: GSE346421)
```

* Reads are mapped to the amplicon (`GBA1_PacBio.gb`) using minimap2. The outputs are:

```
  GBA1_PacBio_aligned.csv
  GBA1_PacBio_filtered.csv
```

* Read and barcode counts feed Supplementary Table 7 (PacBio sequencing). No figure is generated in this step.

### 3. Link barcodes to variants and create the barcode–variant table

* Run `gba1_pb_analysis.ipynb`. This notebook processes the outputs of step 2:

```
  GBA1_PacBio_aligned.csv
  GBA1_PacBio_filtered.csv
```

* It generates the barcode–variant table, together with coverage statistics and QC metrics.
* Generates Supplementary Figure 2 (library composition and barcode coverage) and the library statistics in Supplementary Table 1 and Supplementary Table 7.

### 4. Trim adapters from Flow-Seq sorted barcode sequencing

* Run `trimmomatic_run.sh` to remove 30 nt adapters from the Illumina barcode sequencing reads. This step requires the following fastq files, available from GEO accession GSE346421:

```
  GBA1-Bin1_S1_L001_R1_001.fastq.gz
  GBA1-Bin2_S2_L001_R1_001.fastq.gz
  GBA1-Bin3_S3_L001_R1_001.fastq.gz
  GBA1-Bin4_S4_L001_R1_001.fastq.gz
```

* The outputs are:

```
  GBA1_R1_Bin1_trimmed.fastq.gz
  GBA1_R1_Bin2_trimmed.fastq.gz
  GBA1_R1_Bin3_trimmed.fastq.gz
  GBA1_R1_Bin4_trimmed.fastq.gz
```

* Preprocessing only. No figure is generated in this step.

### 5. Count barcodes in each bin using Enrich2

* Use the configuration files in the `enrich2_counts` folder to run `enrich2_run.sh`. This processes the trimmed reads from step 4.
* This step counts the barcodes in each sorted bin, based on Illumina sequencing of gDNA extracted from the cells, and generates several output files, including:

```
  enrich2_counts/tsv/sort_sel/main_barcodes_counts_unfiltered.tsv
```

* Barcode counts only. No figure is generated in this step.

### 6. Variant scoring

* Run `gba1_flowSeq_analysis.ipynb` to process the Enrich2 count file from step 5:

```
  enrich2_counts/tsv/sort_sel/main_barcodes_counts_unfiltered.tsv
```

* The notebook computes barcode and variant scores, generates empirical p-values, and produces variant–function maps.
* It also uses the barcode–variant table generated by `gba1_pb_analysis.ipynb`:

```
  results/variants/barcode_variant_enrich2.tab
```

* In addition, the notebook produces several of the figures used in the manuscript, along with further QC figures.
* Generates the variant scores used throughout the paper, including Figure 2 (functional atlas heat map and score distributions), Supplementary Figure 3 (score distributions and barcode coverage), Supplementary Figure 11 (barcode scores for selected variants), and the score tables (Supplementary Tables 2 and 7).

> **Note**
> If you only need the variant scores, you can run `gba1_flowSeq_analysis.ipynb` directly, as all the required input files are included in the Zenodo dataset.

## Figure analysis scripts (R Markdown)

The following R Markdown (`.Rmd`) scripts were used to analyse and plot the experimental and annotation data for the manuscript figures.

### Analysis of GCase activity by flow cytometry

**Script:** `LysoFix Time course quantification.Rmd`

* Analysis of flow cytometry data to calculate the staining index for each cell line across different time points following LysoFix treatment.
* This script was used to generate Figure 1B.

**Script:** `Single Variant Analysis_LysoFix Treated.Rmd`

* Analysis of flow cytometry data investigating differences in GCase activity between GBA1 single-variant cell lines following LysoFix treatment.
* This script was used to generate Figure 5.

### Analysis of total protein levels by immunoblotting

**Script:** `Single Variant Analysis_Total GBA1.Rmd`

* Analysis of immunoblotting data investigating differences in total GBA1 protein levels between GBA1 single-variant cell lines.
* This script was used to generate Supplementary Figure 12.

### Analysis of GBA1 MAVE flow-seq scores across structural features

**Script:** `GBA Region Analysis.Rmd`

* This analysis investigates MAVE flow-seq scores for variants associated with previously established GBA1 structural features.
* This script was used to generate Supplementary Figure 5.

**Script:** `Consurf Analysis.Rmd`

* This analysis investigates the correlation between MAVE flow-seq scores and predicted residue conservation scores generated by ConSurf.
* This script was used to generate Supplementary Figure 7.

### Analysis of GBA1 MAVE flow-seq scores and clinical annotations

**Script:** `MDSGene Annotation Analysis.Rmd`

* This analysis investigates the MAVE flow-seq scores for GBA1 variants annotated by MDSGene.
